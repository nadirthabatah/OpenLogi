# These are the OpenLogi brand assets, not OpenRoadie's

Everything in this directory is the OpenLogi logo and icon set, © 2026
AprilNEA, all rights reserved — see [LICENSE](LICENSE), which explicitly
withholds these assets from forks. The files were renamed alongside the rest
of the repository so packaging keeps building, but renaming a file does not
change whose artwork is inside it.

OpenRoadie does not yet have its own logo. Until it does, no release artifact
may ship this artwork under the OpenRoadie name. Replacing this directory's
contents with original OpenRoadie artwork is an open task that blocks any
binary release.
